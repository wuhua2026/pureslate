## 2. 破坏面清单

1. **新增的唯一删除面**：`%SystemRoot%\Temp` 下超过 `maxAgeDays=3` 的普通文件（🟢 direct）。这是 SAFETY §2.1 早已声明的例外，此前未实现（`temp.system` 恒 0 项）。
2. `preflight` 对上述目录的 🟢 目标放行硬保护；其余 SystemRoot 路径不豁免（单测断言 `System32` 仍拦、quarantine 去向仍拦、`is_hard_protected` 仍为 true）。
3. 规则分级调整：浏览器缓存从"隔离区"改为"直接删除"（不再可还原，但可重建、且浏览器运行中跳过）；缩略图/系统临时同理由回收站改为直接删除（回收站不释放空间的语义修正）。
4. 微信缓存**未改**（仍 🟡 隔离区），用户媒体文件不受一键清理影响；大文件审阅型 (R30) 不受影响。
5. 无新增进程/注册表/网络行为。

红线对照：#3 白名单不可碰——例外是 SAFETY §2.1 明文例外且仅限单一目录 + 仅 🟢 去向，`is_hard_protected` 对还原路径不豁免；#1 扫描只读——expand 仅解析路径；#8 🔴 灰禁——未触及。
