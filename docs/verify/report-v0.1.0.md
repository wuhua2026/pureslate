## 4. 功能完成度（六大维度全部接通真实引擎）

- **临时文件**：规则驱动（`system-temp.xml`），🟢 直清（`DeleteFileW`）/回收站（`SHFileOperationW`）双路径，两阶段 journal 事务；
- **大文件**：≥500MB，五层分片并行遍历（87 万文件 23.5s），🟡 隔离区；
- **重复文件**：size → 64KB 采样 → 全量 sha256 三级过滤，仅产出冗余副本（keeper 永不成为清理目标）；
- **应用缓存**：规则驱动（含微信），**进程守卫**：目标应用运行中整类阻止（不做半清）；
- **隐私痕迹**：Edge/Chrome 历史（连 WAL 伴随文件）+ 最近文档，🟡 隔离区；
- **启动项管理**：注册表 Run×3 / 启动文件夹 / 登录触发计划任务五源枚举，禁用 = 备份后移除（可恢复），不删源程序；
- **横切能力**：分级判定（无法判定默认 🔴）、白名单多层强制、隔离区（14 天还原/到期清除/3 天提醒/容量上限）、审计 JSONL（按天滚动/可导出）、崩溃安全（SEH+panic 双通道 minidump + 孤儿事务启动恢复）、单实例、🔴 专家模式 + 后端签发一次性确认令牌。

## 7. 已知偏差与边界（如实记录）

1. **可重复构建降级**：Windows MSVC 链接器默认在 PE 头嵌入时间戳，exe 字节级一致需 `/Brepro`+`SOURCE_DATE_EPOCH` 深度改造——当前双构建哈希**记录**（随 Release 发布供核对），改造挂账；
2. **崩溃上传不接后端**（2026-10-04 决策，R24 裁剪预案）：dump 仅本地保存+预览，`crash_upload` 链路保留但必然优雅失败，Settings 文案已如实注明；
3. **HKLM 启动项 toggle** 需管理员，应用 asInvoker 形态下该项返回失败提示（契约 bool 所限）；
4. **直删 >260 字符路径**优雅失败留盘（隔离区移动不受影响；DeleteFileW 语义）；
5. **large 维度遍历**无中间进度事件（UX 缺口记录在案）；
6. **Minidump 异常流**在本机环境不可用（恒 998）：异常代码经 sidecar JSON 携带；堆损坏/fastfail 类崩溃超出进程内处理器能力；
7. **全部文档公开化治理**只处理了最新版本，历史提交中仍可见（已评估：敏感度为商业/隐私级而非凭据级，接受）。
