# PureSlate · VM 快照回归（R21 · SAFETY §6.1 / TASKS P4-04）

> 目的：在受控 Windows 虚拟机上执行全量清理场景，验证「清理后系统可启动、
> 关键功能正常」——黄金文件集（`golden-misdelete-test`）无法覆盖的真实系统
> 形态（pagefile/注册表/运行中浏览器/Recycle Bin 等）在此收口。
> 执行者：人类（P5-02 使用本手册）；每次发版前（P6-01 净室清单）复跑。
> 记录模板见 §6，结果落 `docs/verify/vm-regression-<日期>.md`。

## 1. 环境准备（一次性）

1. 下载微软官方开发版虚拟机（Microsoft Dev VM，自带 Win11 Enterprise 评估版；
   Hyper-V/VirtualBox/VMware 均可，选与宿主匹配的格式）。
2. 首次开机完成 OOBE（跳过微软账号登录不成功时用临时账号；评估期 90 天足够）。
3. 安装被测应用形态：
   - 安装包（NSIS 产物，CI 下载或本地 `pnpm tauri build`）；
   - 或开发者形态：仓库 + `pnpm install` + `pnpm tauri dev`（验证 dev 路径时用）。
4. 安装验证用第三方软件（触发真实守卫/缓存场景）：
   - 微信（产生 `WeChat Files` 缓存，供 cache.wechat 类目 + 进程守卫用例）；
   - 任一浏览器（Edge 自带即可）。
5. 在 VM 内创建"用户资产"：桌面/文档/图片各放 3-5 个有内容文件（可识别内容），
   下载目录放 2 个 ≥1GB 大文件（供 large 维度）。
6. **打快照**，命名 `pureslate-clean-<版本号>-before`。

## 2. 快照前基线记录（写入记录文档"基线"节）

- [ ] 系统盘剩余空间（`Get-PSDrive C`）；
- [ ] 微信可登录、Edge 可打开任意网页、桌面/文档文件完整；
- [ ] 系统冷启动到桌面时间（秒表粗测）；
- [ ] `C:\pagefile.sys`/`hiberfil.sys` 存在（资源管理器开启系统文件可见）。

## 3. 清理场景执行（核心回归）

在 VM 内依次执行，**每步记录结果**：

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 打开 PureSlate → 一键体检（全维度默认 profile） | 扫描完成出报告；扫描期间系统不卡死 |
| 2 | 检查报告页 | 桌面/文档/图片**不出现**在可清理清单（白名单 §2.4）；下载目录大文件出现在大文件页 |
| 3 | 微信保持登录 → 报告页选择微信缓存类目清理 | 进程守卫拦截，提示"请先退出微信"（整类阻止） |
| 4 | 退出微信 → 重扫 → 清理微信缓存 + 🟢 临时文件 | 执行完成页显示"已释放/已隔离"分项 |
| 5 | 清理期间观察系统 | 无蓝屏/资源管理器崩溃/浏览器异常 |
| 6 | 隔离区页：还原一项刚隔离的文件 | 文件回到原路径可打开 |
| 7 | 隔离区页：确认清空（token 流） | 清空成功，审计日志有 purge 记录 |
| 8 | 日志页导出审计日志 | JSONL 可读，clean/restore/purge 覆盖完整 |
| 9 | 双开 PureSlate | 第二实例退出并激活首实例（P4-02） |
| 10 | 设置页"立即检查更新" | 优雅失败（无网络/未发布），不崩溃 |

## 4. 重启点检（清理后 → 重启 → 验证）

1. **重启 VM**（必须真实重启，非挂起恢复）。
2. 点检清单（全部通过才算零破坏）：
   - [ ] 系统可正常启动到桌面（对比基线启动时间，劣化 >50% 记异常）；
   - [ ] `pagefile.sys`/`hiberfil.sys` 仍在（系统关键文件白名单有效性）；
   - [ ] Edge 可打开网页；下载历史/收藏不丢；
   - [ ] 微信可重新登录（缓存清理不影响账号数据）；
   - [ ] 桌面/文档/图片的用户资产逐一打开核对（内容完整）；
   - [ ] 回收站可正常使用（删除/还原一个测试文件）；
   - [ ] 开始菜单/搜索/设置可打开（系统组件未被波及）；
   - [ ] `<卷根>\.pureslate-quarantine` 存在且属性为隐藏+系统；
   - [ ] PureSlate 可再次启动并正常扫描（二次运行无残留状态问题）。

## 5. 收尾

1. 发现任何异常：截图 + 导出审计日志（`%LOCALAPPDATA%\PureSlate\logs\`）+
   minidump（如有，`%LOCALAPPDATA%\PureSlate\crash\`）→ 记录文档"异常"节 →
   回滚快照复现最小步骤 → 按 P0/P1/P2 分级报 issue。
2. 无异常：记录文档"结论"节 → **恢复快照** `pureslate-clean-<版本号>-before`
   （或删除 VM），保持环境清洁。
